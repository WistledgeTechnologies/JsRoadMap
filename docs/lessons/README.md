# JavaScript Lessons

The course moves from language fundamentals to browser interaction, then to asynchronous work and more advanced language features. Complete the lessons in order where possible.

## Learning path

| # | Lesson | Learner should be able to… | Existing code |
|---:|---|---|---|
| 01 | [JavaScript foundations](01-javascript-foundations.md) | Load JavaScript, use the console, declare variables and identify types | `day1js/` |
| 02 | [Operators, functions and collections](02-operators-functions-and-collections.md) | Calculate, compare, make decisions, write functions and work with arrays/objects | `day2js/` |
| 03 | [DOM, events and browser storage](03-dom-events-and-storage.md) | Select elements, respond to events, render data and persist a simple cart | `day3Js/` |

| 08 | [Destructuring and APIs](08-destructuring-and-apis.md) | Extract values from arrays/objects and consume API data safely | `day8js/` |

## Recommended lesson routine

For each lesson:

1. Read the learning outcomes and key vocabulary.
2. Type the examples yourself; do not only copy and paste.
3. Predict the output before running the code.
4. Change an input and explain how the output changes.
5. Complete the guided practice.
6. Attempt the independent exercises without looking at a solution.
7. Answer the review questions aloud or in writing.

## Course completion project

Build a small product catalogue with:

- A product list stored as an array of objects.
- Product cards rendered into the DOM.
- Category filtering and a search input.
- Add-to-cart and remove-from-cart actions.
- A cart total calculated from product prices.
- Cart persistence using `localStorage`.
- A form for adding a product with validation.
- A loading and error state when loading sample products from an API.

The project is a learning exercise. It is not a production e-commerce system: it has no trusted backend, payment processing, inventory locking or secure user accounts.
